# Dino Dash: Meteor Escape

A cheerful one-file browser game for a child and parent to play together.

## Play

Open the GitHub Pages link on a phone or computer. Landscape mode is recommended on phones.

## Controls

- Arrow keys: Move
- Space: Jump
- X: Star shot (each collected star gives one shot)
- C: Dino cannon
- F: Fly
- D: Dig
- T: Teleport
- I: Invisibility
- A: Parent shield
- S: Super jump

Mobile players can use the on-screen controls. No installation or external assets are required.
